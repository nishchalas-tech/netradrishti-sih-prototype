5. System Architecture & Technology Stack
  • 01IMAGE ACQUISITION — Fundus Camera / DICOM Export / Manual Upload
  • 02QUALITY GATE — Laplacian Focus Score, Illumination (0–255), FOV Coverage, Artifact Check
  • 03IMAGE ENHANCEMENT — CLAHE, Green-Channel Contrast, Unsharp Masking (OpenCV + PIL)
  • 04RETINAL ANALYSIS — NetraNet CNN Forward Pass (PyTorch 2.x, CPU/GPU)
  • 05DR GRADING — Binary: NON-REFERABLE / REFERABLE → ICDR 0–4 Demo Label Mapping
  • 06EXPLAINABILITY — Grad-CAM Spatial Attribution (conv4 hook) — Real model attention visualization
  • 07TRIAGE — High Priority / Routine Queue Assignment → JSON persistence (state_manager.py)
  • 08DOCTOR REVIEW — Tele-Ophthalmologist Decision Dashboard (FastAPI + SPA)
  • 09RESOURCE SIMULATION — Python Discrete-Event Model (Awaiting MATLAB/Simulink integration)
